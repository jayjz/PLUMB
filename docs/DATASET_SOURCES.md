## Reuse boundary and reproducibility

Public access does not establish redistribution permission. Federal employee works may be public domain in the United States, but incorporated third-party material is not automatically so; see [USAGov's government-copyright guidance](https://www.usa.gov/government-copyright). We did not establish a blanket PDF license and do not redistribute the originals, tables, graphics, referenced ASTM/AMPP standards or third-party expressive text. Cases contain original fictional prose and short original factual notes. No source's publication is treated as endorsement. No repository-wide license is added.

Original downloads are preserved under ignored `runs/source-cache/` in the authoring workspace. They are not available in a fresh checkout. `python3 scripts/validate_exp002.py --source-cache runs/source-cache` checks all downloaded bytes against the manifest. Ordinary CI verifies metadata, note/case linkage and frozen repository hashes **without claiming to reverify remote PDF content**. To reproduce the source audit, obtain the public artifacts via manifest URLs and retain the exact bytes only where permitted; if a publisher updates them, a hash mismatch is an unresolved provenance difference, not permission to rewrite the freeze. GitHub metadata snapshots are API responses, not repository licenses. Derived local `.txt` files are inspection aids, not original downloaded artifacts.

No authentication walls, rate limits or paywalls were bypassed. No commercial customer records, executed change orders, private bids or field measurements were obtained. Thirty traceable **source-informed synthetic** cases are feasible with the five verified downloads; thirty real-world cases have not been obtained.
